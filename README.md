# Task01 - Text Analyzer

## 📌 Proje Amacı

Bu proje, .NET ve C# öğrenme sürecinin ilk görevi olarak geliştirilmiştir.

Amaç; kullanıcıdan alınan veya bir metin dosyasından okunan metni analiz ederek temel C# yapılarını öğrenmektir.

---

## 🎯 Görev

Program iki farklı şekilde metin alacaktır.

1. Kullanıcının konsoldan metin girmesi
2. `metin.txt` dosyasından metin okunması

Daha sonra alınan metin üzerinde çeşitli analizler yapılacaktır.
